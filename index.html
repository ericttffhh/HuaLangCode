📌 變數與常數

使用「變數」、「設」、「令」宣告可變變數，使用「常數」宣告唯讀變數：

設 分數 = 95;
常數 圓周率 = 3.14159;

📌 條件判斷 (若 / 否則若 / 否則)

若 (分數 >= 90) {
  印出("特優");
} 否則若 (分數 >= 60) {
  印出("及格");
} 否則 {
  印出("不及格");
}

📌 迴圈控制 (當 / 從...到...循環 / 遍歷)

// 計數循環
從 1 到 5 循環 (i) {
  印出("計數：", i);
}

// 遍歷陣列
遍歷 ["蘋果", "香蕉", "芒果"] 於 水果 {
  印出("水果：", 水果);
}

📌 自訂函式

函式 計算總和(甲, 乙) {
  回傳 甲 + 乙;
}
印出(計算總和(10, 25));
